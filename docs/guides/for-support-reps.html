For support reps

How to use the agent to handle a ticket or a refund.

Guides: Overview For support reps For approvers

Sign in

Open the console and choose Sign in as alice. That's you — a support rep. The agent will act with your authority, so it can only do what you're allowed to do.

Ask the agent

  1. Type what you want in the box, in plain words. For example:
    • Get the profile of customer c-100
    • Issue a refund of 200 dollars for order o-1001
    • Draft a reply to ticket t-5001
  2. Press Run. The agent picks the right tool and tries it.
  3. Read the result card.

Reading the result

You seeWhat it means
okDone. The answer is shown below it.
approval_requiredThe action is too risky to do automatically. It's now waiting for a manager. Nothing has happened yet.
deniedThe rulebook does not allow this. It won't happen, no matter how it's asked.
Why was my refund held?

Refunds above a small limit need a manager's approval — that's a policy, not an error. The agent has already asked; you don't need to do anything else. The manager will see it in their queue.

What the agent can and can't do for you

It can

Look up customers and orders, read tickets, draft replies, quote refunds, and issue small refunds.

It can't — without a manager

Issue a refund over the small limit, or read a customer's personal details (name, email, phone).

It never

Issue a refund above the hard ceiling, run bulk actions, or act as anyone other than you.

Good to know

  • If a task is worded vaguely, the agent might pick a different tool than you expected — just be specific about the customer/order and the amount.
  • Every action you take through the agent is recorded against your name. That's normal and it protects you.
  • Nothing is “sent” to a customer by the agent — drafting a reply only saves a draft.
